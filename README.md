# Prova de Conceito (PoC) - BDD com Cucumber.js

Este repositório contém a Prova de Conceito (PoC) desenvolvida para a disciplina de Engenharia de Software, demonstrando a aplicação prática do **Behavior-Driven Development (BDD)** utilizando a sintaxe **Gherkin** e a biblioteca **Cucumber.js**.

## 🎯 Objetivo da PoC
Demonstrar a rastreabilidade dinâmica entre a escrita de requisitos de negócio em linguagem natural e a sua execução automatizada como testes de software.

## 🛠️ Tecnologias Utilizadas
- **Node.js**: v22.21.0
- **Cucumber.js**: ^13.3.0
- **Gherkin**: Especificação em Português (`# language: pt`)

## 🚀 Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone [https://github.com/BiancaSantozz/bdd-poc-autenticacao.git](https://github.com/BiancaSantozz/bdd-poc-autenticacao.git)
   cd bdd-poc-autenticacao
2. Instale as dependências:
    ```bash
    npm install
3. Execute os testes BDD:
    ```bash
    npm test
